Catan Coach

Local Settlers of Catan coach: C++20 rules and MCTS advice, PyTorch value-net training from self-play, and a browser UI you run on your machine.

View on GitHub Quick start

Run it on your machine

The playable coach isn’t hosted in the browser — it needs the local engine and PyTorch for Train.

  1. Clone the repo
  2. Build and start with make ui
  3. Open http://127.0.0.1:8765/
git clone https://github.com/rhayenga/ML-Game-Theory-Strategy-Game-Engine.git
cd ML-Game-Theory-Strategy-Game-Engine
make -j4
make ui

What’s inside

Legal-move engine, strategy eval, MCTS coach, harbor-aware play, PyTorch self-play training, opening visit memory, and an end-of-game recap.
